## Export Settings for Scheduling

When your 7 slides are finalized in Canva:

1. **Download as PNG** — each slide as a separate file (File → Download → PNG → check "Download pages as separate files")
2. **File naming:** `meridiana-slide-01.png` through `meridiana-slide-07.png`
3. **Upload each to Google Drive** → right-click → Share → "Anyone with the link can view" → copy the share URL for each
4. **Convert each Drive URL** from `https://drive.google.com/file/d/FILE_ID/view` to `https://drive.google.com/uc?export=download&id=FILE_ID`
5. **Paste all 7 URLs** into the Metricool carousel scheduler (see below)

## Scheduling via AICC

Once you have the 7 public image URLs, use the new carousel endpoint:

```
POST /api/metricool/schedule-carousel
```

```json
{
  "video_id": "<your video_tracker row ID for this carousel>",
  "image_urls": [
    "https://drive.google.com/uc?export=download&id=SLIDE_1_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_2_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_3_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_4_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_5_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_6_ID",
    "https://drive.google.com/uc?export=download&id=SLIDE_7_ID"
  ],
  "publish_datetime": "2026-07-16T09:00:00",
  "caption_override": "<paste the caption from docs/carousel-content.md>"
}
```

The endpoint will schedule to Instagram at Thursday 9am CT and return the Metricool confirmation.
